# Что такое Qwenity?

Qwenity Это Локальный ИИ-чатбот на Python с использованием Ollama.

Версия проекта: 1.0

Возможности
- Общение с локальной языковой моделью.
- Сохранение истории диалогов в JSON.
- Поддержка нескольких чатов.
- Продолжение предыдущих диалогов.
- Обработка ошибок при запросах.

## Используемые технологии
- Python
- Ollama
- HTTPX
- JSON

## Установка и запуск

1. Установите [Python](https://www.python.org/) и [Ollama](https://ollama.com/).
2. Скачайте проект.
3. Установите зависимость:

```bash
pip install httpx
```

4. Загрузите модель:

```bash
ollama pull qwen3:4b
```

5. Запустите программу:

```bash
python main.py
```
